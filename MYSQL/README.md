# MySQL Database & SQL Fundamentals

A structured learning and reference section covering **MySQL databases, SQL fundamentals, database operations, PHP–MySQL integration, relational concepts, and data management**.

This directory is part of the [Web-Application-Penetration-Testing](../) repository and provides foundational database knowledge that supports web application development, testing, and security research.

---

## Overview

MySQL is an open-source relational database management system widely used in web applications. This collection focuses on understanding how relational databases are structured, how SQL is used to work with data, and how PHP applications interact with MySQL.

The material progresses from database fundamentals and SQL commands to more application-oriented topics such as PHP database connectivity and data retrieval.

---

## Learning Path

**Database Fundamentals → SQL Commands → Data Manipulation → PHP–MySQL Connectivity → Queries & Operators → Schema → Keys & Relationships → Data Retrieval & Management**

## Why This Matters for Web Security

Understanding databases is an important foundation for web application security testing. Knowledge of SQL structure, database relationships, query behavior, and application-to-database communication helps security practitioners better understand vulnerabilities involving database-backed applications.

This repository also contains separate material dedicated to **SQL Injection**, while this directory focuses primarily on MySQL and database fundamentals.
