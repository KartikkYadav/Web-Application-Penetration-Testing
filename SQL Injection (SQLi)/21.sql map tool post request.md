# 🟩 **Sqlmap Tamper Scripts**

Sqlmap tamper scripts are Python scripts used to modify SQL injection payloads before sending them to the target server. Their main purpose is to bypass Web Application Firewalls (WAFs), Intrusion Prevention Systems (IPS), or input filters that block or sanitize SQLi payloads. Tamper scripts transform the payload to evade detection while retaining its intended effect.

---

# 🟦 **Why Use Tamper Scripts?**

- Some web applications block or sanitize typical SQL injection payloads.
- Tamper scripts help bypass these defenses by altering payload syntax.
- They allow exploitation of SQLi vulnerabilities that might otherwise remain hidden.
- Customized tamper scripts can be created for unique filtering environments.

---

# 🟧 **How Tamper Scripts Work**

- They process each injection payload just before sqlmap sends it.
- Transformations include encoding, obfuscation, replacing spaces, comments, or special characters.
- Multiple tamper scripts can be combined in a single scan.

---

# 🟨 **Using Tamper Scripts in sqlmap**

### List all available tamper scripts:

```

sqlmap --list-tampers

```

---

---

# 🟩 Use one or more tamper scripts by specifying the `-tamper` option:

```
sqlmap -u "http://target.com/vuln.php?id=1" --tamper=space2comment,between

sqlmap -r <saved_request.txt> --random-agent --proxy=http://127.0.0.1:8080 --tamper=space2comment,between --risk=3 --level=5 --threads=10

```

---

# 🟦 **Common Tamper Scripts**

- **space2comment** : Replaces spaces with SQL comments to bypass simplistic filters.
- **between** : Replaces equal signs with BETWEEN expressions.
- **randomcase** : Randomizes the case of SQL keywords.
- **charencode** : Encodes characters using `CHAR()` function.
- **base64encode** : Encodes payloads in Base64.
- **appendnullbyte** : Appends a null byte to the payload.
- **equaltolike** : Replaces equals (=) with LIKE operator.
- **modsecurityversioned** : Bypasses specific ModSecurity rules.

---

# 🟧 **Creating Custom Tamper Scripts**

- Write Python scripts defining a
    
    `tamper(payload, **kwargs)` function.
    
- The script modifies the **payload** string and returns the transformed version.
- Place custom scripts in sqlmap’s `tamper/` directory.
- Use them via:
    - `-tamper=yourcustomscript`

---

---

# 🟩 **Best Practices**

- Start testing without tamper scripts to identify vulnerable points.
- Use tamper scripts only when default payloads are blocked or sanitized.
- Combine multiple tamper scripts if needed.
- Test one script at a time to isolate effective payload alterations.
- Always verify the impact on target behavior to avoid false negatives.
