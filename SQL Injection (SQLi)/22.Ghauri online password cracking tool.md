

# 🌑🔵 **Ghauri**

🔗 **Ghauri**

**Ghauri** is an advanced cross-platform tool that automates the detection and exploitation of SQL injection vulnerabilities.

GitHub Repository: **https://github.com/r00th3x49/ghauri**

# 🔄 **Workflow — Capture POST Request in Burp → Run With Ghauri**

1. **Configure Burp Proxy**
    
    Point your browser to Burp’s default proxy:
    
    **127.0.0.1:8080**
    
2. **Trigger the POST request**
    
    Perform the action in the web app (login, form submit, search, etc.) so that Burp captures the POST request.
    
3. **Locate & Save the Request**
    
    *In Burp:*
    
    - Go to **Proxy → HTTP History** (or **Intercept → Forward**)
    - Find the request
    - **Right-click → Save item** *(or)*
    - **Right-click → Copy → Copy request / Save request**
    
    ✔️ *Save only the raw HTTP request (not the response).*
    
    Suggested filename: **sqli-post1.txt**, **req.txt**, etc.
    
4. **Verify the Saved File**
    
    Open it to check it contains a valid raw HTTP request. **Example:**
    

```
POST /vuln.php HTTP/1.1
Host: target.example.com
User-Agent: Mozilla/5.0
Cookie: PHPSESSID=abcd1234
Content-Type: application/x-www-form-urlencoded
Content-Length: 18

id=1&name=test

```
