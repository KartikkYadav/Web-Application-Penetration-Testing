

## 🔷 Second-Order SQL Injection

Second-order SQL injection tab hota hai jab user input pehle safely database me store ho jata hai, lekin baad me stored data bina sanitization ke SQL query me use hota hai, jisse vulnerability aa jati hai.

---

## 🛠️ How It Works

- **First-order SQL Injection:** Bina sanitize kiye user input direct SQL query me use hota hai 🚨
- **Second-order SQL Injection:** User input pehle safe store hota hai (is stage pe koi vulnerability nahi) 😇
- Later, wahi stored data bina sanitize kiye phir se SQL query me use hota hai ⚡
- Is second use se SQL injection vulnerability hoti hai 🐞

---

## 💻 Example Scenario in PHP

1. **User Input Stored:** Malicious user input deta hai, jisme SQL code ho sakta hai (e.g., `'; DROP TABLE users; --`) — yeh input safely database me store ho jata hai 🗄️
2. **Later Retrieval:** Wahi stored input baad me fetch karke bina sanitize kiye dusri SQL query me lag jata hai (e.g., `SELECT * FROM users WHERE username='$stored_input'`) 🧐
3. **Injection Occurs:** Malicious payload retrieval query ke time execute ho jata hai 🧨

---

## 🛡️ Prevention

- Hamesha parameterized queries/prepared statements ka use karein, chahe data insert kar rahe ho ya retrieve kar rahe ho 🚦
- Kabhi bhi stored data ko direct SQL command me concatenate mat karein bina sanitize kiye 🚫

---

## 🏁 Summary

Second-order SQL injection tab hota hai jab safe storage ke baad, stored data ko unsafe tarike se SQL ke andar use kiya jaye—yeh subtle lekin dangerous attack hai! 💣

# 🧪 **Example Scenario in PHP**

1. **User Input Stored:** A malicious user submits input containing SQL code (e.g., `'; DROP TABLE users; --`) which is stored literally in the database.
2. **Later Retrieval:** This stored input is later fetched and concatenated unsafely into another SQL query (e.g., `SELECT * FROM users WHERE username='$stored_input';`).
3. **Injection Occurs:** The malicious payload gets executed during the retrieval query.

```
<?php
// fetch.php
// This page demonstrates second-order SQLi: it fetches the `username` by id (safe),
// then uses that stored username inside a concatenated SQL query (unsafe).
// Example: stored username = ' OR '1'='1    will alter the constructed query.

require_once 'config.php';

$id = isset($_GET['id']) ? intval($_GET['id']) : null;

// Step 1: Fetch stored username safely
$username = null;

if ($id !== null) {
    $stmt = $mysqli->prepare("SELECT username FROM users WHERE id = ?");
    $stmt->bind_param("i", $id);
    $stmt->execute();
    $stmt->bind_result($username);
    $stmt->fetch();
    $stmt->close();
}

// Step 2: Use stored username unsafely → second-order SQL injection
$result = null;

if ($username !== null) {
    // Vulnerable query — stored malicious username will inject here
    $unsafe_query = "SELECT * FROM users WHERE username = '$username'";
    $result = $mysqli->query($unsafe_query);
}
```

# 📝 **insert.php (Full Code)**

```
<?php
// insert.php
// Inserts a user record. Uses prepared statement so storing is safe (payload stored verbatim).

require_once 'config.php';

if ($_SERVER['REQUEST_METHOD'] == 'POST') {

    // Accept id, username, email from POST
    $id       = isset($_POST['id']) ? intval($_POST['id']) : null;
    $username = isset($_POST['username']) ? $_POST['username'] : '';
    $email    = isset($_POST['email']) ? $_POST['email'] : '';

    if ($id === null || $username === '') {
        echo "id and username are required. <a href='insert.php'>Back</a>";
        exit;
    }

    // Prepared statement: stores the username safely (no SQL injection at this step)
    $stmt = $mysqli->prepare("INSERT INTO users (id, username, email) VALUES (?, ?, ?)");
    if (!$stmt) {
        die("Prepare failed: " . htmlspecialchars($mysqli->error));
    }

    $stmt->bind_param("iss", $id, $username, $email);
    $ok = $stmt->execute();
    if (!$ok) {
        echo "Insert failed: " . htmlspecialchars($stmt->error) . "<br>";
    } else {
        echo "User stored safely. ID={$id} Username=" . htmlspecialchars($username) . "<br>";
    }

    $stmt->close();
    echo "<a href='insert.php'>Back</a> | <a href='fetch.php'>Admin fetch</a>";
    exit;
}
?>
```
