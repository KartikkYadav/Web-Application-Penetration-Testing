### Disable PHP Error Display

To improve security by hiding detailed PHP errors from users, edit the PHP configuration and restart the Apache web server as follows:

- **Edit the PHP configuration file:**
    
    ```bash
    vim /etc/php/7.3/apache2/php.ini
    
    ```
    
- **Set `display_errors` directive to Off:**
    
    ```bash
    display_errors = Off
    
    ```
    
- **Save and exit the editor.**
- **Restart Apache service to apply changes:**

systemctl restart apache2

# 🔵 Boolean Conditions (Always True / False)

**Force the condition to always be true or false:**

- `1' AND 1 --` (always true)
- `1' AND 0 --` (always false)
- `1' AND 1 #` (always true)
- `1' AND 0 #` (always false)
