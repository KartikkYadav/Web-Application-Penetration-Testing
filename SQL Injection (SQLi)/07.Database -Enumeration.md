# Database -Enumeration:

**Database-Enumeration**

---

### 💠 MySQL Basic Commands and Database Enumeration

- **Log in to MySQL as the root user**
    
    ```bash
    mysql -u root -p
    
    ```
    
- **Show all databases available on the MySQL server**
    
    ```sql
    SHOW DATABASES;
    
    ```
    
- **Switch to the "mysql" database (contains user accounts and privilege data)**
    
    ```sql
    USE mysql;
    
    ```
    
- **List all tables within the current database**
    
    ```sql
    SHOW TABLES;
    
    ```
    
- **Display all records from the "user" table (contains MySQL users and privileges)**
    
    ```sql
    SELECT * FROM user;
    
    ```
    
- **Show only usernames and their password hashes**
    
    ```sql
    SELECT user, authentication_string FROM user;
    
    ```
    

---

### 💚 Exploring Information Schema

- **Show all databases again**
    
    ```sql
    SHOW DATABASES;
    
    ```
    
- **Switch to the "information_schema" database**
    
    ```sql
    USE information_schema;
    
    ```
    
- **List all tables across all databases**
    
    ```sql
    SELECT * FROM TABLES;
    
    ```
    
- **Display only database names (schemas) for each table**
    
    ```sql
    SELECT TABLE_SCHEMA FROM TABLES;
    
    ```
    
- **List unique database names**
    
    ```sql
    SELECT TABLE_SCHEMA FROM TABLES GROUP BY TABLE_SCHEMA;
    
    ```
    
- **Fully qualified version (explicitly specifying the schema)**
    
    ```sql
    SELECT TABLE_SCHEMA FROM information_schema.TABLES;
    SELECT TABLE_SCHEMA FROM information_schema.TABLES GROUP BY TABLE_SCHEMA;
    
    ```

## 💾 Retrieving Database Details from `information_schema`

### 1️⃣ **List All Databases (Schemas)**

Shows all databases stored in the MySQL server.

```sql
SELECT schema_name FROM information_schema.schemata;

```

---

### 2️⃣ **List All Tables from All Databases**

Retrieves every table name along with the database (schema) it belongs to.

```sql
SELECT table_schema, table_name
FROM information_schema.tables;

```

---

### 3️⃣ **List All Columns of Each Table**

Displays every column name, its table, and database.

```sql
SELECT table_schema, table_name, column_name
FROM information_schema.columns;

```

---

### 4️⃣ **Find Sensitive Columns (e.g., passwords, users, etc.)**

Searches for column names containing words like `pass`, `user`, or `email`.

```sql
SELECT table_schema, table_name, column_name
FROM information_schema.columns
WHERE column_name LIKE '%pass%'
   OR column_name LIKE '%user%'
   OR column_name LIKE '%email%';

```

---

### 5️⃣ **Retrieve File and Directory Info (System Tables)**

Useful for **advanced enumeration** — shows MySQL’s internal files and storage info.

```sql
SELECT * FROM information_schema.files;

```

---

💡 **Tip:**

`information_schema` is a goldmine for **enumeration** — it helps attackers or admins discover **hidden databases, sensitive columns, stored procedures, and even file metadata** inside MySQL without requiring direct access to application-level data.

## 💾 **Exploring database, table, and column metadata using the `information_schema` database**

---

### 🧩 **List all tables in all databases (showing both schema and table names)**

```sql
SELECT TABLE_SCHEMA, TABLE_NAME
FROM information_schema.TABLES;

```

🟢 *This lists every table in every database accessible to the user.*

---

### 🎯 **Filter by a specific database**

👉 Enumerate tables only in the `"mysql"` system database:

```sql
SELECT TABLE_SCHEMA, TABLE_NAME
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'mysql';

```

---

### ⚙️ **Using LIMIT (to restrict output)**

Example: Retrieve just the first table entry for the `"mysql"` database 👇

```sql
SELECT TABLE_SCHEMA, TABLE_NAME
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'mysql'
LIMIT 0, 1;

```

---

### 🧠 **Querying columns metadata**

```sql
SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'mysql'
  AND TABLE_NAME = 'columns_priv';

```

🟣 *Lists all columns of the `"columns_priv"` table in the `"mysql"` database.*

---

### 🧱 **Similar example for the `user` table**

```sql
SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'mysql'
  AND TABLE_NAME = 'user';

```

💡 *This retrieves column details (like `User`, `Host`, `authentication_string`, etc.) for the MySQL user table.*

---

### 🔍 **Direct queries on the `mysql.user` table**

```sql
SELECT User, Host, authentication_string
FROM mysql.user;

```

## 🚀 **Extra Examples**

### 🧮 1️⃣ **Find all databases**

```sql
SHOW DATABASES;

```

---

### 🧮 2️⃣ **List all tables in the current database**

```sql
SHOW TABLES;

```

---

### 🧮 3️⃣ **List all columns in a specific table**

```sql
SHOW COLUMNS FROM employees;

```

*or*

```sql
DESCRIBE employees;

```

---

### 🧮 4️⃣ **Get column metadata across all schemas**

```sql
SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME, DATA_TYPE
FROM information_schema.COLUMNS
ORDER BY TABLE_SCHEMA, TABLE_NAME;

```

---

### 🧮 5️⃣ **Find tables containing a specific column name (e.g., “password”)**

```sql
SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME
FROM information_schema.COLUMNS
WHERE COLUMN_NAME LIKE '%password%';

```

✨ *Very useful during SQL injection enumeration or DB analysis!*
